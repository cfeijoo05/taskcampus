# Constitución del Proyecto TaskCampus

## Tecnologías y Herramientas
- **Frontend:** TypeScript, HTML5, Vite y Tailwind CSS (versión 4).
- **Backend:** Python con el framework Flask.
- **Persistencia:** Archivo local JSON (`tasks.json`) para simular base de datos no relacional.

## Principios de Desarrollo
- La API debe seguir una arquitectura RESTful y las respuestas deben estar en formato JSON.
- El código del frontend debe estar tipado estrictamente con interfaces de TypeScript.
- No se utilizarán variables hardcodeadas para las rutas de la API en producción.
